# Estação Lana — Site Institucional

## Como rodar o projeto

### Pré-requisitos
- Node.js 18+ instalado

### Instalação

```bash
# 1. Instalar dependências
npm install

# 2. Rodar em modo desenvolvimento
npm run dev

# 3. Abrir no navegador
# http://localhost:5173
```

### Build para produção

```bash
npm run build
npm run preview
```

## Tecnologias
- React 18
- Tailwind CSS 3
- Vite 5
